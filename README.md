# Football Alert System — React + Tailwind

The original football frontend rebuilt as a React + Tailwind project while keeping the existing visual style and assets.

## Header / pages

- `Home` — displays the complete original home-page content.
- `Matches` — displays only the `Matches` page name, with a blank body and the same footer.
- `Players` — displays only the `Players` page name, with a blank body and the same footer.
- `Blog` — displays only the `Blog` page name, with a blank body and the same footer.
- `News` — displays only the `News` page name, with a blank body and the same footer.
- `Contact` — displays only the `Contact` page name, with a blank body and the same footer.

The header remains visible while navigating between pages and includes the new `News` item.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The project uses React Router and Tailwind CSS. The source assets remain under `public/images` and `public/fonts`.
